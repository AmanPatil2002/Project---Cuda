# Cuda

A responsive and visually appealing landing page project built with HTML and CSS. This project showcases a modern one-page website layout with sections for services, team members, skills, portfolio, and contact.

## Features
- Clean and modern hero section
- Services cards with icons and descriptions
- Team section with profile information
- Skills progress display
- Portfolio gallery layout
- Contact form and footer links

## Technologies Used
- HTML5
- CSS3
- Font Awesome Icons

## How to View
1. Open the project folder in your browser.
2. Launch the index.html file to see the landing page.
